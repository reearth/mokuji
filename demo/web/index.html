Mokuji address lookup

Addresses from Japan’s Address Base Registry in one static file. No server, no API, no database: the page fetches byte ranges out of index.mokuji and reads the index itself. Watch the request count while you type.

Opening the file is paid once and reads the resident set — the header, the term index, and the offset tables. Every keystroke after that costs a handful of range requests whose number depends on how many results come back, not on how large the file is.

The index records that it was built with the ja-address tokenizer, so the page puts your query through the same normalization the addresses went through. That is why typing 一丁目 finds 1丁目. The registry spells chome both ways depending on the municipality.

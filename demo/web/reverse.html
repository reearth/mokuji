The orange outlines are what the index returned; the blue one is what survived the point-in-polygon test the page runs itself. That gap is the design: a cell straddling a boundary names every polygon it touches, so a lookup narrows the answer without deciding it. The dashed rectangle is the geohash cell your click landed in.

The file records which geohash precisions it holds, under geohash-precisions in the application-defined metadata the specification reserves. The page reads that rather than assuming it, so it makes two lookups instead of seven. See demo/reverse/README.md for how the covering is built and what it costs.

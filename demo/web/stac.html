A static STAC catalog, searched

Maxar Open Data publishes its catalog as static STAC: JSON files you follow from catalog.json down to each item. Nothing there answers which images cover this place in this week — that is what a STAC API server is for. Here the same question is answered by one static stac.mokuji beside the catalog, with a handful of range requests.

Each item is indexed under three kinds of term: the words of its collection's title (w:), the geohash cells its bbox touches at five precisions (g1:–g5:), and its date (d:). A query is the intersection of the three. A period is a range of date terms, read in one walk because dates written as YYYY-MM-DD sort in the order of time. Cloud cover is a resident column, so filtering by it costs no request at all.

The orange rectangles are what the index returned; the blue ones also touch the map as the page sees it. A cell can touch the view when the item inside it does not, so the index narrows and the page decides. Only the first 50 matches are fetched and drawn.
